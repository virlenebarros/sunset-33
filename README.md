# Sunset 33 - Convite

Convite de aniversario em pagina unica (HTML + CSS + JS) para publicacao rapida no GitHub Pages.

## Estrutura

- `index.html`: pagina principal do convite
- `assets/audio/sunset.mp3`: trilha usada no botao de play

## Edicoes rapidas

1. Texto principal: edite os blocos dentro de `.hero` e das `section` no `index.html`.
2. Data e horario: procure por `12/09` e atualize.
3. Local: procure por `Beira-mar` e ajuste o ponto.
4. RSVP WhatsApp: troque o `href` do link com classe `.rsvp`.

## Publicar no GitHub Pages

1. Suba este repositorio para o GitHub.
2. No GitHub: Settings > Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main` e pasta `/(root)`.
5. Aguarde 1-3 minutos e abra a URL gerada.

## Checklist antes de enviar

- Testar no celular
- Confirmar data, horario e local
- Testar botao de musica
- Testar link do WhatsApp
